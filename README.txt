S.P.E.A.R COMPLETE LOCAL PACKAGE
================================

1. Extract this ZIP to a folder.
2. Double-click Run-SPEAR.bat.
3. Keep both server windows open while using the site.
4. The page opens at http://127.0.0.1:5500.

The backend accepts the frontend from localhost or 127.0.0.1 on any local
HTTP port, so the browser can connect if the website server selected another
port. Open the website through its local HTTP address, not by double-clicking
index.html.

The launcher starts the website and its local backend. Python 3.10 or newer is
required. If port 5500 or 8000 is already in use, close the other S.P.E.A.R
server windows and run the launcher again.

The AI Guide is an offline, rule-based educational helper. It explains email
spoofing concepts and can summarize the latest report. It does not use a
generative AI service, verify emails, or certify that a message is safe.
